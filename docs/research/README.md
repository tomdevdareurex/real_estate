# Research

Notes about the Lithuanian property market. **Nothing here describes this codebase**, and no code
depends on it.

It sits in the repository because the scraper exists to serve this analysis: the fields worth
extracting, and the reason a listing's price history and area matter more than its photo count,
come from here rather than from anything in `src/`.

| --- | --- |
| [apartment_flipping_lithuania.md](apartment_flipping_lithuania.md) | Cap rates, renovation budgets, breakeven analysis, risk, and a comparison against index investing. |
| [lithuanian_real_estate_sites.md](lithuanian_real_estate_sites.md) | Lithuanian valuation and market-research sites, filtered to ones genuinely tied to the local market. |
